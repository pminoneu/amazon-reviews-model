# Proposal Data Dictionary

## Original data files

- `data/All_Beauty.jsonl.gz`: original review records. Each line is a JSON object containing fields such as product identifiers, rating, review text, timestamp, and purchase-verification status. Manual decompression is unnecessary.
- `data/meta_All_Beauty.jsonl.gz`: product metadata. This analysis uses product titles only for explanation or display. Crawl-time prices and cumulative rating totals are not treated as information available at the 20th-review cutoff.

## Product-level tables

`results/product_summary.csv` contains 5,709 rows, with one row per `parent_asin`. `product_features.csv` contains the same rows and split assignments plus `early_text`, which combines the first 20 review texts and may contain line breaks. Use pandas or a CSV reader that supports quoted multiline fields.

| Column | Definition | Role |
| --- | --- | --- |
| `parent_asin` | Parent product identifier, which can group color, size, or other variants | Sample identifier; not a predictor |
| `cutoff_timestamp` | Unix timestamp in milliseconds for the 20th review after exact-record deduplication | Prediction cutoff |
| `cutoff_utc` | Readable UTC representation of the same cutoff | Explanation and validation |
| `early_rating_mean` | Mean star rating of the first 20 reviews | Early feature |
| `days_to_20` | Elapsed days from the first review to review 20; fractional values are retained | Early feature |
| `early_verified_share` | Fraction of the first 20 reviews with verified purchase, from 0 to 1 | Early feature |
| `early_low_rating_share` | Fraction of the first 20 reviews rated at most 2 stars, from 0 to 1 | Early feature |
| `early_text` | The first 20 review texts combined in order; present only in the features table | Early feature |
| `later_review_count_365d` | Number of reviews strictly after the cutoff and within the following 365 days | Outcome construction only; must not be used as a predictor |
| `later_rating_mean_365d` | Mean rating in the same subsequent window; blank when there are no reviews | Outcome construction only; must not be used as a predictor |
| `is_successful` | 1 if subsequent review count is at least 24 and subsequent mean rating is at least 4.0; otherwise 0 | Binary target |
| `split` | `train` or `test` | Fixed split assignment |

## Summary and verification files

- `dataset_overview.csv`: dataset sizes, filtering counts, split sizes, and label-threshold summary.
- `target_distribution.csv`: label counts and shares. `share` is a fraction from 0 to 1.
- `baseline_scores.csv`: test results for always predicting the training majority class, 0. `tn`, `fp`, `fn`, and `tp` are confusion-matrix counts. Because there are no positive predictions, positive precision has a zero denominator; it is stored as 0 under the explicit `zero_division=0` convention.
- `random_product_example.csv`: the product row selected with seed 42 for the report, together with its display title.
- `audit.json`: detailed statistics, source URLs, and SHA-256 hashes of the original files.
- `verification.json`: results from the earlier independent arithmetic checks and raw-record inspection.
- `package_verification.json`: results generated by running the verification script included in this package.

## Definitions to preserve

1. The review file contains 112,565 distinct parent products; the metadata file contains 112,590 rows. These counts describe different populations.
2. Reviews are grouped by `parent_asin`. Exact duplicate JSON records are removed before sorting by timestamp and original source order.
3. A product is eligible only when a full 365-day window after its 20th review falls within the dataset's observation period. The endpoint is the maximum timestamp in the entire review file. This does not establish continuous product availability or complete review capture for each product.
4. Outcome reviews must occur strictly after the cutoff. Additional reviews with exactly the cutoff timestamp are excluded from the subsequent window.
5. The training set's 75th-percentile threshold is 24. Do not recalculate it on the test set. Integer ties mean that the criterion of at least 24 reviews need not select exactly 25% of products.
6. The target represents review performance, not actual sales or profit. A product with no subsequent observed reviews receives target 0, which does not mean it had zero sales.
7. The revised 5,709 samples and 14.6% overall positive rate reflect deduplication and a training-derived threshold. The original idea in `references/` reports 5,787 samples and 14.2%; use the revised report and results for this submission.
